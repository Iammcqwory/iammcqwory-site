# IAMMCQWORY Site

Astro static portfolio for IAMMCQWORY (Makori Brian), a Nairobi-based founder, filmmaker, and AI strategist.

## Project structure
- `src/pages/index.astro`: homepage and structured data.
- `src/styles/global.css`: site styling.
- `public/site.js`: venture-tab interaction.
- `public/llms.txt`: AI discovery guide.
- `public/index.md`: Markdown twin of the homepage.
- `public/skill.md`: capability guide for AI agents.

## Commands
- `npm run dev`: run the local development server.
- `npm run build`: create a production build.
- `npm run preview`: preview the production build.

## Content rules
- Keep the position clear: Founder. Filmmaker. AI Strategist.
- Keep Nairobi and African-founder-building-globally prominent.
- Use the Waziri Collective Labs line verbatim: "We don't pitch AI transformation. We find the thing breaking your operation and fix it."
- When changing visible venture or service content, update `public/index.md` and `public/llms.txt` as well.
